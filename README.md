# Replicator

Repositorio de complementos (add-ons) de Home Assistant para los sistemas Nexus.

Replicator lleva el stock y las compras de la casa: sacás una foto del producto y se suma o se descuenta solo, con ayuda de IA.

## Instalación

En Home Assistant: **Configuración → Complementos → Tienda de complementos → ⋮ → Repositorios**, y agregá:

```
https://github.com/Sysmika/replicator
```

> El complemento todavía está en desarrollo y se publicará en este repositorio más adelante.
